凭据策略
  • 加密存储
    Token、密钥统一由 forge-server SecretService 加密落库，界面永不回显明文。
  • 仅 Server 可读
    forge-agent 不持有任何外部凭据，只通过声明权限的受控 Tool API 间接访问。
  • 按集成独立轮换
    每个集成的凭据与签名密钥独立配置，支持轮换与连通性校验，轮换即时生效。
  • 使用即审计
    凭据的读取、解密与外部系统调用全部记录审计日志，越权访问会被拒绝并留痕。
